                            多模态与安全说明：

                                自定义维度 JSON 配置编辑器
                            

                            
可在此处编辑自定义的题型、难度等级（含颜色）以及层级教学大纲树状结构。

                        

                        

                            预设模板一键载入：
                            
                            
                            
                            
                        

                    

                    
                    

                        
                    

                    
                    

                        
配置说明：

                        
1. question_types: 题型列表。例如：{"value": "single_choice", "label": "单选题"}。

                        
2. difficulties: 难度等级列表。必须包含 value, label 和 color 属性。color 使用 Tailwind CSS 类名控制徽章样式。

                        
3. curriculum: 树状大纲目录结构。格式为："学段名称": {"章节名称": ["知识点/小节1", "知识点/小节2"]}。修改并保存后，AI 智能分类与试卷智能拆解将立刻感知并应用新大纲！
