# MathBank - 本地化数学题库与组卷排版工作台

> 🏷️ **项目标签**：数学题库 | 高中数学 | 备课教研 | A4 Live Preview | 智能组卷 | XeLaTeX 排版 | TikZ 几何绘图 | LaTeX 公式 | OCR 公式识别 | DeepSeek AI | 教育技术 (EdTech)

🎉 **MathBank** 是一个为中学数学教师量身打造的、完全本地化运行的轻量级半自动化数学题库与组卷排版工作台。

本项目追求**极简的配置**、**零构建的轻量依赖**与**极致的本地体验**，开箱即用，内置 LaTeX 公式与 TikZ 几何图形秒级渲染引擎，并深度集成了组卷排版工作台、A4/A3 Live Preview 画布、高考级 PDF/XeLaTeX 编译导出，以及主流大语言模型（DeepSeek / 阿里百炼 / GPT-4o / Claude 等）与多通道 OCR 接口。

## 🎯 项目设计初衷与定位

MathBank 最初源于真实一线高中数学教研与备课场景，在功能体系与设计上具有鲜明的实用与教研特色：

- 📑 **全流程组卷排版工作台**：集成了从「题目精细研讨」到「试卷排版组装」的双工作台无缝切换。提供纯前端秒级渲染的 A4 Live Preview 画布，支持密封线、注意事项、双向 WYSIWYG 标题编辑、解答题留白调控、插图位置切换与 A3 答题卡/高考 19 题预设。
- 🖨️ **高考级 XeLaTeX 编译与 0ms 缓存**：内置 `exam-zh` 高考排版宏包（完整内置 21 个扩展依赖库，彻底解决本地排版环境依赖），支持一键导出高清 PDF 和完整 XeLaTeX 源码包 (.zip)。采用 MD5 哈希与插图时间戳防碰撞 LRU 内存缓存，相同试卷 0ms 瞬间复用。
- 🤖 **AI 智能组卷与教学理推理**：依托核心解题大模型，融入中学数学教学教研思维（双向细目表、知识点覆盖率与难度阶梯分布），可一键从题库中智能筛选组装最适配的试卷组合。
- 📚 **多教材大纲预设与无感迁移**：系统已原生内置并适配了 **「人教A版」**、**「人教B版」** 以及 **「苏教版」** 的高中数学教材大纲预设。当您切换预设模板时，系统会自动在后台对题目执行智能增量对齐，实现多套大纲大范围无感迁移与多版本身份同时共存。
- 🔍 **精细化题目教研与标签体系**：系统支持「易错题」、「常规题」、「挑战题」与「强基题」四档难度，注重对高质量、有代表性的题目进行精细化收集与 AI 辅助深度教研，配合自定义 Tag 徽章与双向关联题组（变式题/子母题）管理。

## ⚙️ 维度自定义与标签系统 (免代码个性化)

系统提供了极具弹性的自定义大纲与难度映射机制，您无须修改任何 Python 或 HTML 代码，即可直接在网页端实现完全的学科与教材解耦：

1. **自定义大纲与难度/题型配置（大纲版本一键切换）**：
   - 点击网页右上角的 **「设置 (齿轮)」** 按钮，切换到 **「维度配置」** 选项卡。
   - **大纲版本一键切换**：在面板顶部，您会看到 **「预设模板一键载入：人教A版 / 人教B版 / 苏教版」** 三个按钮。直接点击您想要的教材版本，下方的配置框中就会瞬间载入对应的标准大纲与默认难度题型设置。点击底部的 **「保存配置」** 按钮即可完成切换。
   - **自由编辑**：除了载入预设，您还可以直接在此处的文本框内修改 JSON 配置，自定义您所需要的学段级联（如 `高中物理`、`初中数学`）、章节与知识点大纲、自定义题型及难度（含颜色代码），保存后立即生效。

2. **题目自定义标签 (Tags)**：
   - 在题目编辑界面，支持为每道题/试卷添加个性化标签（如 `年级`、`期中`、`真题`、`重难点` 等）。
   - 标签输入框中**支持使用逗号分隔**（中英文逗号均可，如 `高一,期中,真题`），系统将自动将其渲染为精致的黄底小徽章（带标签图标 🏷️）。
   - 录入标签后，在左侧检索栏中输入标签内容，系统将自动进行快速模糊匹配。同时终端命令行检索工具和 AI 只读题库也同步支持该字段。

## 🌟 核心特性

- 🧪 **极简技术栈与 100% 离线支持**：后端基于 `Python + FastAPI + SQLAlchemy`，数据库使用轻量级 `SQLite`；前端使用纯 `HTML + JavaScript`（无编译、无捆绑），且核心资源（Tailwind CSS, FontAwesome, KaTeX 等）均已本地化，支持完全的离线使用和本地公式秒级渲染。
- 📑 **组卷排版工作台 & A4 Live Preview 实时渲染**：
  - **双工作台无缝切换**：顶部导航栏提供动态 Dropdown 工作台切换（“题库研讨工作台” ↔ “组卷排版工作台”），状态自动持久化。
  - **A4 仿真 Live Preview**：纯前端 DOM 1:1 仿真渲染 A4 试卷（210mm x 297mm），支持密封线、卷头大标题、副标题与注意事项框。
  - **WYSIWYG 标题编辑**：支持在侧栏或 A4 Live Preview 画布上自由打字双向修改主副标题，零闪烁零失焦。
  - **解答题留白内联调控**：解答题下方实时渲染浅蓝虚线留白区，提供 `[-1cm]`、`[+1cm]` 等快捷内联微调按钮，留白高度随试卷自动存库并与 LaTeX 精确同步。
  - **插图排版位置联动**：插图支持 `right`（题干右侧混排）、`center`（居中）、`bottom_right`（下方居右）位置切换，自动与 LaTeX 导出的 `wrapfigure`/`adjustbox` 对应。
  - **HTML5 原生拖拽排序**：支持拖拽试题卡片灵活调整卷面题目顺序。
  - **已保存试卷管理**：组卷结果存入本地 `papers` 数据库，支持历史试卷列表一键全量载入组卷工作台、快速编译 PDF 与删除等全生命周期管理。
- 🖨️ **高考级 XeLaTeX/PDF 编译引擎与 LRU 哈希缓存**：
  - **三大标准试卷模板**：内置 `exam`（常规试卷）、`quiz`（日常小练）、`exam_19`（新高考 19 题专属答题卡联动卷，按 LaTeX3 整数变量自动跳跃题号）。
  - **0ms LRU 字节缓存**：基于全套 LaTeX 源码 MD5 哈希与关联插图修改时间戳的线程安全内存缓存（容量 50），相同源码瞬间复用 PDF 字节流。
  - **零依赖自愈编译**：全量内置 `exam-zh.cls` 及 21 个关联 helper 宏包，旧版 TeX Live 无需安装额外扩展包即可直出试卷。
  - **Windows GBK/UTF-8 平滑解码**：进程级解码，彻底解决命令行 UTF-8/GBK 混用导致的 Unicode 崩溃。
- 🤖 **AI 智能组卷与多模态教研工作流**：
  - **AI 智能组卷**：调用解题大模型结合双向细目表、知识点分布与难度阶梯分布，自动挑选试卷题目组合。
  - **三合一解答工作流**：支持手动录入、AI 智能生成（DeepSeek 步骤推导）、OCR 图像识别（阿里百炼、硅基流动等双通道）。
  - **双阶段 TikZ 几何绘图与 VLM 自动重绘**：单题 OCR 识别到插图时，自动调用多模态大模型（GPT-4o / Qwen-VL）生成 TikZ 代码并编译 PNG 插入题干。
  - **PDF 试卷多模态拆解与手动截图**：支持上传 PDF 文件，后台 PyMuPDF 高清栅格化与 VLM 并行识别，支持指定解析页码范围（如 1-6 页过滤答案），前端提供灯箱拖拽框选高精截图。
- 📚 **多教材大纲身份共存与自动增量对齐**：原生支持人教A版、人教B版、苏教版三套教材大纲，独创“活跃-镜像模式”，不同大纲下的分类记录独立保存，切换预设大纲时系统智能自动对齐映射，免去繁杂的手动对齐步骤。
- 📐 **LaTeX / KaTeX 公式排版规范自愈**：
  - **选择题 choices 环境规范**：OCR 识图与入库统一将选项解析存储为 LaTeX `choices` 环境（使用 `\begin{choices}` 和 `\item` 包裹，自动剥离 `A.`, `B.`, `C.`, `D.` 标号前缀），前端与 LaTeX 引擎依据字符长度自适应网格排版（≤10字 1行4列，≤24字 2行2列，>24字 1行1列）。导出 AI 题库时自动清洗为 Markdown 标准列表。
  - **填空题 \fillin 宏规范**：多模态 OCR 识图与试卷拆解 Prompt 强置将下划线生成为标准的 `\fillin` 宏（代替旧版 `______` 或 `\underline{\hspace{...}}`），前端 KaTeX 默认渲染为 1.5cm 标准精美下划线。
  - **选择题题干末尾括号净化**：后端、前端预编译与迁移脚本联动，自动物理抹除题干末尾录入的全角/半角供填答空括号（如 `(\quad)`、`(   )`、`（  ）`），彻底规避与 LaTeX 试卷模板右侧 `\paren` 括号重叠。
  - **右侧插图顶格组装算法**：消除 `minipage` 盒子的外层 2em 缩进与折行悬挂，确保多问解答题在右侧插图窄版下 100% 绝对顶格对齐。
- 📂 **自动存储清理与净化**：编辑或删除题目时，物理删除废弃图片；服务启动 2.5 秒后自动运行 1 小时安全线的孤儿图片防误删净化。
- 🔒 **AI 专属只读题库备份**：后台写入时自动生成 `data_backup/questions_library.md`（AI 专属题库），自动清洗 Markdown 不兼容排版命令，且**彻底过滤答案与解析**，保障备课和 AI 命题时的隐私安全。
- 💻 **CLI 极速模糊检索**：内置终端检索工具 `search_questions.py`，支持在终端通过命令行快速查询知识点和题干。

```text
http://127.0.0.1:8000
```

## 🔄 版本升级与数据备份

本题库系统的所有核心数据均存储在本地。当发布新版本时，您可以通过以下方式进行安全升级：

### 方式 A：使用 Git 升级 (最推荐 ⚡)
如果您是通过 `git clone` 获取的项目，直接在项目根目录下执行：
```bash
git pull
```
- **安全性**：100% 安全。由于您的本地数据库 (`*.db`)、API 密钥 (`.env`)、自定义维度配置 (`data_backup/`) 以及上传的插图 (`static/uploads/`) 均已被 Git 忽略，因此 `git pull` **绝对不会**覆盖或影响您的任何本地数据和个人配置。

### 方式 B：使用 Release 便携包覆盖更新 (需注意 ⚠️)
如果您是下载 Release 压缩包 (`MathBank-Windows-x64.zip` 或 `MathBank-macOS.zip`) 使用的用户：
1. **覆盖式更新**：直接将压缩包解压，把新版本的文件**覆盖/合并**到现有的项目文件夹中。
   - 由于 Release 压缩包中不包含任何数据库文件和自定义配置文件，覆盖解压是安全的，您的数据会得以保留。
2. **⚠️ 危险防范（防误删）**：
   - **千万不要**在解压新版本前**彻底删除**旧的项目文件夹。
   - 在覆盖拖拽解压时，如果系统提示“替换”或“合并”，**必须选择“合并”或直接覆盖**，不要选择可能会直接删除旧目录的整包替换选项。

## 🔍 本地终端命令行检索

为了方便在编写教案、备课时快速访问本地题库，本项目在根目录下提供了一个高效的模糊检索命令行工具 `search_questions.py`。

在终端中运行（例如搜索包含“导数”的题目）：
```bash
python3 search_questions.py -q "导数"
```

**参数说明**：
- `-q` : 检索的模糊关键词（匹配学段、章节、知识点、题干）
- `-n` : 限制返回数量，默认最多 50 条（使用 `-1` 为无上限）
- `-a` : 携带答案和解析（默认只拉取题干，安全防泄露）
- `-t` : 题型过滤（如 `single_choice`, `multi_choice`, `fill_in_blank`, `detailed_answer`）
- `-d` : 难度过滤（`easy`, `medium`, `hard`）
- `-r` : 查询与特定 ID 题目发生双向关联的全部题目

## 🛠️ 数据迁移与自愈工具

系统针对历史遗留题目数据与最新的 OCR / LaTeX 格式规范提供了全自动化的数据库清洗与自愈脚本：

1. **填空题下划线全量升级 (`python3 migrate_fillin.py`)**：
   - 扫描 SQLite 数据库中所有已入库题目，自动将题干中遗留的旧下划线格式（如 `______`、`\underline{...}`、`\fillin[...]`）一键平滑清洗规范为标准的 `\fillin` 宏。
   - 运行完成后自动触发备份落盘，同步刷新 JSON 备份与 AI 专属只读题库。

2. **选择题题干末尾空括号物理净化 (`python3 migrate_choice_parentheses.py`)**：
   - 扫描数据库中所有选择题，物理抹除题干末尾录入的各种全角/半角供填答用空括号（如 `(\quad)`、`(   )`、`（  ）`），彻底规避与 LaTeX 试卷模板右侧自动生成的 `\paren` 括号产生二次重叠。
