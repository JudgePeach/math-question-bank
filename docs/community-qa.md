# 社区 QA 的来源与维护

## 范围与取舍

本次审阅用户提供的 MathBank 群聊 JSON 中全部 **1,541 条消息记录**，北京时间覆盖 **2026-09-08 至 2026-10-03**，合并为 **36 条问答、7 个主题**。记录按时间分段逐条审阅，并交叉读取分段边界；采用有明确群主答复的问答和后续更正，不把社区猜测当作群主结论。

“全部消息记录”不等于所有附件内容：本次另核对了 11 张与产品答复相关的截图，没有逐张识别全部图片，也没有读取群内的 3 个示例 PDF。仅有附件而没有可靠文字或已核对截图证据的报错，没有推测根因。导出缺失或未包含的历史聊天不在本次范围内。

问答是整理后的简述，不是原聊天转录。原始聊天、图片、群号、成员账号、消息全局 ID、个人联系方式、推广链接及凭据均不入库。保留的 `sources[].answerSeqs` 只是原导出的消息序号，配合北京时间日期供持有原始资料的人复核；页面只显示日期，不公开原始记录。

## 内容结构

`static/js/qa-data.js` 是唯一内容源，每条包含：

- `id`：稳定的英文标识，不随标题措辞调整。
- `category`、`question`、`answer`、`keywords`：主题、问题、纯文本段落和检索关键词。
- `sources`：群主回答的北京时间日期与消息序号；不记录发言人的账号信息。
- `currentNote`（可选）：根据当前代码核对的补充说明，页面明确标为“当前代码核对”，不伪装成群主原话。

正文中的 LaTeX 和 Markdown 示例有意按原文显示，便于用户知道应输入哪些符号；不经过公式或 HTML 渲染器。新增来源时必须读完上下文，检查后续是否已纠正，并同步调整覆盖时间。不要加入未经实际确认的模型兼容、价格、额度或“保证成功”描述。

## UI 与状态边界

复用本地 PhysicBank 新增的 QA 导航与独立工作区结构，在 MathBank 上填充可离线检索的问答。沿用现有主题、桌面侧栏和手机底栏；通过共享的 `selectWorkspace` 切换，从导入退出后恢复 QA。没有新增后端接口、数据库表、外部请求或模型调用。

`qa.js` 使用 DOM `textContent` 和原生 `details/summary`，搜索支持大小写/全半角归一化及多关键词交集，分类与搜索叠加。筛选只隐藏节点，保留展开状态；重置同时清空搜索和分类。刷新仍沿用主系统规则回到首页，不清空题库、草稿、组卷选择或试卷信息。

资源顺序为 `qa-data.js` 后 `qa.js`，均加入 `main.py` 的资源版本戳。发布构建已有 `static/js` 白名单，不新增前端依赖。
